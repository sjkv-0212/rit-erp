# RIT Student Management UI Clone

This is a front-end recreation of the Ramco Institute of Technology Student Management / Leave & On-Duty portal shown in the supplied screenshots.

## Run
Open `index.html` in Chrome/Edge.

## Included
- Fixed blue RIT header
- Scrollable department sidebar
- Leave & On-Duty application form
- Student information cards
- Application type selector
- Search / type / status filters
- Application table with approval flow cards
- Approved / Pending status pills
- Responsive mobile layout
- Simple interactive submission toast

This is a visual/front-end clone. It does not connect to the college's real student-management database or authentication system.
